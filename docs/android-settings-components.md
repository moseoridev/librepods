# Settings UI component provenance

The independent [`:settings-ui` library](../android/settings-ui/README.md) supplies presentation primitives to `BudsDeviceSettings`. State, capability checks, text/artwork, navigation and commands belong to the caller. The current visual reference is **Manager9.0.10.1724 on S25/API37**. Source-backed rules, Compose adapters and measured runtime scope are distinct.

## Product composition check

The product retains the iOS AirPods information structure. The [settings reference](android-settings.md) owns the screenshot catalog, current presentation limits, pixel/motion results and cost measurements. Matching a primitive does not establish Apple feature support or whole-screen Manager equivalence. Generic inquiry/log sheets, purchases and quick settings are compatibility consumers, not screenshot completion criteria.

## Integration and verification boundary

Public primitives do not depend on the app ViewModel, Bluetooth, model enums or app resources. Optional Samsung font/window behavior has explicit fallbacks. Caller options, text, item counts and artwork remain generic. Geometry/source matching is not proof of arbitrary state, accessibility hit-bound, theme, locale, animation, firmware-command or battery parity. Cold profile/cache candidates were rejected; no timing patch or pixel/density compensation is retained.
